# Git & Vercel – from your first commit to a live deployment

This tutorial teaches you how to build websites like a professional and put them online.

The beginning is a bit of a slog. We install a few tools and then have to get to grips with Git. By the time we reach branches at the latest, it gets a little complicated and long-winded. But we need these basics for Part 3, where we build the actual website.

For Part 3 I promise you will feel like a superhero. In a matter of minutes you will pull off what used to take software developers hours or days.

## Who is this tutorial for?

This tutorial is first and foremost for anyone who wants to know how to build websites with AI. The tools we use for that also require Git. That is why the tutorial teaches you Git as well.

If you already know Git, you can skip [Part 2](/en/part-2/).

You do not need any prior programming knowledge. You should know how to install programs and how to work with files and folders.

## What you need

- a computer running **Windows 10 or 11**
- an internet connection
- an email address to sign up for GitHub, Vercel and Claude
- We use Claude Code to build the website. It costs around €20 per month, and you can cancel any time. A ChatGPT subscription works just as well – in that case you use **Codex** instead of Claude Code. The screenshots show Claude Code, but the process is the same.

## What you will learn

### [Part 1 – Setup](/en/part-1/)

You create accounts at GitHub, Vercel and Claude and install all the tools: VS Code, Git with Git Bash, Node.js and Claude Code. Finally you connect VS Code to GitHub.

### [Part 2 – How does Git work?](/en/part-2/)

You learn what a commit is and how to commit in the terminal and in VS Code. You create branches, work with GitHub as a remote repository, merge branches and resolve your first merge conflict.

### [Part 3 – Astro & Vercel](/en/part-3/)

You create your first Astro project, upload it to GitHub and connect it to Vercel. From then on, every change you push goes online automatically.

## This site is an example of itself

This tutorial site was built exactly the way you are about to learn: it is an **Astro project**, it lives **publicly on GitHub**, and every change is published automatically through **Vercel**.
